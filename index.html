Trích xuất hóa đơn GTGT → Excel

Mọi xử lý diễn ra ngay trên trình duyệt — không file nào được tải lên máy chủ.

1
Hóa đơn
Nạp PDF hóa đơn (hoặc .zip / thư mục) → tải Excel theo mẫu. Có thể nạp lại file Excel đã xuất.
2
Inbound SAP
Dùng danh sách PO SCAF để tải báo cáo ZMME0032 trên SAP, nạp vào đây → điền cột SỐ LƯỢNG (K), CHECK.
Kéo thả vào đây: PDF hóa đơn · ZIP · thư mục · Excel đã xuất · file Inbound SAP
